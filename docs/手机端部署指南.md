# 手机端部署指南

写完这份指南前，我把 MNN Chat 的源码读了一遍。有几个地方跟网上流传的说法**不一样**，照抄会踩坑。

---

## 0. 先分清两套格式（选错 App 等于白下）

| 形态 | 文件 | 体积 | 只能喂给谁 |
|---|---|---|---|
| **MNN 格式** | `llm.mnn` + `llm.mnn.weight` + `tokenizer.mtok` + `llm_config.json` + `config.json` | 166 MB | 只有 MNN Chat |
| **GGUF** | `*-Instruct-Q4_1.gguf` | 183 MB | llama.cpp 系 |

官方明确表态：**"MNN Chat is not based on llama.cpp, so cannot use gguf models"**
（[issue #3902](https://github.com/alibaba/MNN/issues/3902)）

---

## 路线 A：PocketPal AI + GGUF（推荐给普通人）

**不需要电脑、不需要 adb、不需要开发者账号。**

1. 手机装 **PocketPal AI**
   - 安卓：[Play 商店](https://play.google.com/store/apps/details?id=com.pocketpalai)，或侧载 [GitHub Releases](https://github.com/a-ghorbani/pocketpal-ai/releases)
   - iPhone：[App Store](https://apps.apple.com/us/app/pocketpal-ai/id6502579498)（⚠️ 国区大概率搜不到，需美区/港区 Apple ID）
2. 把 `MNN-Pocket-0.3B-Instruct-Q4_1.gguf`（183 MB）传进手机
   - 安卓：数据线 / 微信传文件
   - iPhone：AirDrop 或"文件"App 存到「我的 iPhone」
3. App 里 **☰ → Models → ＋ → Add local model → 选那个 .gguf → Load**

架构标注是 `qwen3`，PocketPal 现版本都认。

---

## 路线 B：官方 MNN Chat（更小更快，但绑定 adb）

### ⚠️ 三个网上不会告诉你的坑

**坑 1：路径不是 sdcard**

源码 `LocalModelsProvider.kt` 里路径是**写死**的：

```kotlin
val modelsDir = File("/data/local/tmp/mnn_models/")   // 不是 sdcard！
if (modelDir.isDirectory && File(modelDir, "config.json").exists())  // 必须有 config.json
```

**坑 2：App 里没有文件选择器**

`MainActivity.kt` 那个「增加本地模型」按钮，点开弹出的就是一条 adb 命令。全 App 没有 SAF/DocumentFile 选文件逻辑。

**坑 3：官方模型市场里根本没有这个模型**

实测 `model_market.json`：prod 130 个模型、dev 148 个模型，**零个 Pocket / 0.3B 条目**。只能侧载。

### 操作步骤

```bash
# 1. 装 App（41.8 MB，来自官方 CDN）
#    https://meta.alicdn.com/data/mnn/apks/mnn_chat_0_8_3.apk
#    手机点开安装（允许"安装未知来源应用"）

# 2. 推模型
adb shell mkdir -p /data/local/tmp/mnn_models
adb push MNN-Pocket-0.3B-MNN /data/local/tmp/mnn_models/

# 3. 打开 App → 模型列表筛「本地」→ 出现 MNN-Pocket-0.3B-MNN → 对话
```

### 硬件要求

- **只能装 arm64-v8a**（32 位、x86 装不上）
- Android 8.0+（`minSdk 26`）
- RAM 4GB 以上绰绰有余（峰值约 300MB）
- 官方只保证 OnePlus 13 / 小米 14 Ultra 测过

### 如果报 `Load module failed`

模型卡写明：INT4 tied-embedding 布局要求 runtime 与导出属同一 MNN 版本族。

换 [0.8.2.2](https://meta.alicdn.com/data/mnn/apks/mnn_chat_0_8_2_2.apk)（这版专门修了「Add Local Model」崩溃）再试。

### iOS 走这条路基本无望

App Store 有 [MNN Chat](https://apps.apple.com/app/mnn-chat/id6748348797)（iOS 17+、免费），但它的「本地模型」只列内置模型和已下载模型，没有 Files 导入入口。README 的本地调试法是"把模型目录拖进 Xcode 重新编译"。

**→ iPhone 用户请走路线 A。**

## 路线 C：手机当遥控器（算力在电脑上）

自建了一个零依赖的 Node 服务 + 手机聊天界面。

### 启动

```bash
# 1. 起模型服务
llama-server -m MNN-Pocket-0.3B-Instruct-Q4_1.gguf \
  --chat-template-file chat_template.jinja \
  --host 127.0.0.1 --port 8471 -c 8192 -ngl 99

# 2. 起 Web 服务
node scripts/server.js
```

### 访问

**别记 IP，用这个**：`http://127.0.0.1:8472/qr`

页面上显示**当前真实可用**的地址和二维码，服务每次启动都会重新读网卡。

> 为什么强调这个：我实测时第一次抓到 `10.35.11.158`，十分钟后路由器 DHCP 换成了 `172.28.37.182`，网络位置还从「专用」变成「公用」。**写死 IP 一定会失效。**

### 前提

手机和电脑连同一个 Wi-Fi。node.exe 的防火墙入站规则 Private 和 Public 都要放行。
